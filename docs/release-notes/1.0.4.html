Insomniac 1.0.4

Notarized — no more Terminal step

Insomniac is now signed with a Developer ID certificate and notarized by Apple. New installs just open: no “can’t be verified” warning, and no xattr command to paste into Terminal. If you ran that command for an earlier version, you never need to again.

Automatic updates

Insomniac can now check for updates on its own and install them for you — this update is the last one you’ll have to fetch by hand. Every update is cryptographically signed and refused if the signature doesn’t match. You can turn automatic checks off in Settings → General.

Open at login

A new Settings → General → Open at login switch starts Insomniac with your Mac.

Fixes

  • The welcome window no longer reappears on every launch — it’s first-run only now, with a Show button in Settings if you want it back.
  • Installing the privileged helper for silent toggling now takes effect immediately. Previously it kept asking for your password until you quit and reopened the app, which made the feature look broken.
  • Closing the lid while the menu was open could be missed entirely, leaving the screen on. Power-source changes had the same problem, so a low-battery auto-stop could be delayed.
  • Launch is quicker: the startup check for a leftover keep-awake no longer blocks the app while it runs.
  • The “what’s keeping your Mac awake” list is read straight from the system now instead of being scraped out of command output — it’s more accurate and costs far less battery while the System tab is open.
